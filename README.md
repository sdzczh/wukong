# 无敌悟空（文字塔防）

文字合成塔防游戏（H5）。地府题材：抽字召唤、相邻合成神将、镇守黄泉路，抵御幽魂进攻轮回殿；局外魂晶 + 天赋树永久成长。

> 状态：**2.0 路线图 #36–#50 全部交付**。线上：<http://43.99.15.109/>。设计方案见 [设计文档.md](设计文档.md)。

## 玩法

- **目标**：守住轮回殿 10 波幽魂进攻。怪物沿黄泉路漏过即扣心，心归零则败。
- **无尽征战**：通关第 10 波后可选择继续——波次不设上限，敌人血量按 1.14^(n-1) 逐波膨胀，每过 5 波奖励 1 把铲子（无尽补给），可无限开垦地块；心归零按实际波次结算（魂晶 = 波次×10 + 击杀），历史最高波次入档。
- **随机战场**：每局随机路线（入口列 / 横穿行 / 出口列共 27 种组合，鬼门关与轮回殿位置随之移动），黄泉路横贯 9×13 全陆棋盘；并随机开放 16 个起始地块（其中 10 个贴近路径）。
- **抽字召唤**：消耗蟠桃一次弹出 **5 张卡**点选入架（没选的卡下次召唤时消失，可整轮放弃）；普通字（弓/枪/棍/营/毒/雷/冰/锤）直接成塔，神将字先成「灵字塔」，凑成对才能唤醒神将。
- **卡片分级（自走棋式）**：普通字卡随波次升级——第 2 波起出 Lv2（概率每波 +5%、上限 35%），第 6 波起出 Lv3（每波 +4%、上限 20%）；神将字恒 Lv1。高级卡放下即为对应等级，同字同级叠放继续升。
- **合成**：
  - 两个同字同级的单位叠放 → 升级（字塔满 5 级；不同级只能换位）；
  - 神将字对相邻 → 合成神将（悟+空→孙悟空），共 12 位神将；
  - 两个同级的同名神将叠放 → 神将升级（3 级，杀敌得经验，自动施放专属技能；无尽征战中神将等级不设上限）。
- **缘引机制**：已持有某对字的一半时，另一半权重 ×4；整轮 5 卡无神仙字记一次保底，连续 4 轮必出神将字（天赋可缩短）。
- **阵容思路**：弓点杀、枪穿刺、棍横扫、战鼓给周围 2 格内友塔 +15% 攻速；毒染毒叠层（无视护甲）、雷连环跳、冰减速、锤削甲，Lv3 后各可花桃二选一进阶；12 位神将各有主动技（击退、链弹、全屏震慑、斩杀标记等）。
- **灵宝掉落**：击杀概率掉落蟠桃、全体 +20% 攻击（15 秒）、+1 心；无尽征战第 10 波后掉率每波 ×0.85 衰减，防止后期灵宝泛滥。
- **利息**：每波肃清后按当前蟠桃数发息钱——每持有 10 桃 +1，单波上限 +5，鼓励理财运营。
- **选牌刷新**：召唤的 5 张卡不合意可花 3 桃整轮换一批（保底计数不受影响）。
- **字卡处理**：长按架子上的字卡弹出面板——普通字卡可直接出售（+2+等级 桃）；神将字卡可献祭给场上对应神将（+6 经验），也可直接卖。卡架被神将字占满时有正当出路。
- **神将经验**：按击杀强度给经验（幽魂 1 / 怨灵 1 / 游魂 1 / 阴山力士 2 / 鬼将 4）；每波肃清保底 +1 经验（无尽征战无保底）；升级需求 8 + 4×(等级-1) 线性递增，配合无尽无上限形成长跑曲线。
- **战鼓成长**：战鼓光环每级范围 +0.15 格、攻速 +5%（1 级 2.2 格 +15%，5 级 2.8 格 +35%），自身不攻击。
- **每日轮回**：主菜单独立入口，按当天日期播种——全场玩家同一张地图，比谁走得更远；最佳波次当日入档，结算页展示。
- **装备系统**：击杀概率掉装备部件（厉魂掉率更高），3 个同系部件合成 Lv1 装备，3 件同系同级再合成升级（满 Lv3）。四系：**兵锋**攻击+、**疾风**攻速+、**望远**射程+、**灵犀**神将技冷却-。点装备再点塔佩戴（战鼓为阵眼不可装备；灵犀仅神将可佩），出售/铲除塔时装备自动回库。
- **神将专属**：12 位神将各有 1 件专属神兵（金箍棒、风火轮、昊天镜……）。鬼将（boss）必掉 1 枚专属碎片，优先掉落场上神将；**碎片带出对局永久保留**（败局也不丢），主菜单「装备库」3 碎片合成 Lv1、2 碎片/级升满 Lv5（图鉴点亮后可操作）。装备库行内给出**下一级数值预览**与**碎片进度条**，可操作行金框高亮、顶部汇总可合成/可升级数，碎片不足或未点亮点击有明确提示，底部附局内四系装备图例。局内唤醒对应神将自动随身，主属性 + 专属强化（如金箍棒每级旋棍 +0.5s、昊天镜每级威压眩晕 +0.15s）。
- **神将攻击特效**：12 位神将普攻各有独立视效（`atkfx` 数据驱动，`FX.sweep`/`FX.beam` 统一入口，普通塔保持默认样式）——悟空金色厚弧带白芯双段、悟能紫弧带落点冲击环、玉帝超长距金弧；金吒蓝白粗光束、杨戬紫色细光柱、李靖草绿粗光；悟净水珠、哪吒火尖枪、木吒双刃、王母花瓣、阎王墨团、嫦娥月牙，均带拖尾与命中火花，嫦娥技能万箭同用月牙弹。
- **地块开垦**：开局随机开放 16 格（10 格贴近路径 + 6 格全图随机），其余地块以「封」字锁定；用铲子（每局 10 次）点「封」字格开垦新地块，也可点单位将其铲回架子。
- **索敌优先级**：点塔详情面板可切换「最先 / 最近 / 最强 / 最后」，默认最先（沿路最前），四模式随战况自由换。
- **提前叫波**：备战期点「提前叫波」立即开怪，按剩余秒数 ×2 结算奖励蟠桃，精打细算多一份开局收入。
- **蟠桃出口**：备战期底栏上方横排「瑶池祝福」三项临时增益随购随用——回心 30 桃立即 +1 心、疾风 45 桃本波全员攻速 ×1.25、定身 40 桃本波敌速 ×0.6，每波每项限购一次、价格每购 +10、过波即失效；点芯片先弹确认框（显示价格与效果，防手滑），已购/心满/桃不足时直接提示不弹框，开波或选牌时确认框自动收起；装备栏打开或召唤选牌条出现时祝福条自动让位。铲子用完后短按铲子钮（有铲时长按）花桃补铲，50 桃起每把 +15。后期蟠桃溢出（无尽尤其）有正当去处。
- **波间三选一词条**：每 3 波过波后弹出 3 张随机全局词条（全体攻击/攻速/经验/冷却/经济/战鼓光环/出售价，另有即时 +2 心、+2 铲），选 1 张永久叠加，选牌期间不开下一波。
- **精英词缀怪**：第 6 波起普通怪概率带词缀——裂（死亡分裂 2 只小怪）、盾（护盾吸收、破盾 5 秒后回满）、疗（为周围敌人持续回血）、疾（移动 +60%），精英血量与掉落翻倍。
- **每周异变**：主菜单入口，按 ISO 周播种——整周全场同一张图、同一套 3 个全局修正（急魂夜行、厚甲幽都、丰收之年、字价低廉、聚财、脆弱之体、悟性超凡、地脉丰饶、神将降临随机取 3），每周最佳波次入档。
- **羁绊系统**：12 神将分 4 阵营——三吒同心（攻速）、天庭威仪（攻击）、取经之路（经验）、散仙结盟（技能冷却）；场上同阵营 2 位激活一层、3 位激活两层，凑阵是后期阵容的另一维深度。
- **伤害统计**：每塔伤害本局累计，点塔详情显示本塔伤害，结算页输出伤害榜前三。
- **存档码**：主菜单「存档迁移」生成一串口令（复制去换机），粘贴导入即可恢复魂晶/天赋/图鉴/碎片与异变纪录；同页可进「云端同步」用设备码自动接进度。
- **局外成长**：每局按「波次×10 + 击杀 + 图鉴首解」结算魂晶，在主菜单「修炼」中点天赋：破棍（攻击）、摘星（财运召唤）、长生（防御），另有隐藏天赋「齐天荣耀」。
- **图鉴等级区分**：图鉴自动记录每张卡的历史最高等级并分层展示——字页签每格右上「最高 Lv2/Lv3」徽章（蓝/金边框与底色分层、Lv3 带金晕），页签下统计「已识 x/y 字 · Lv2 n 张 · Lv3 m 张」；神将页签解锁卡右上「实战 Lv」徽章（对局内合成/经验升级也计入）、附「随身 · 专属 Lv」行（联运局外装备库等级），未唤醒卡提示合成所需两字并勾出已集齐的一半（如「悟✓ + 能」），页签下统计已唤醒/随身专属件数；记录只升不降、随存档码跨机携带。
- **操作**：点选架子上的字再点棋盘放下（放下不弹详情，不遮挡战场；点塔仍可查看详情与出售）；**双击架子卡**自动合成场上同字同级的单位（神将字则自动与配对字塔凑对唤醒神将），场上没有目标时自动改找**架上**同字同级/配对目标合成，都没有则提示原因；**两张架子卡互拖也可直接合成**（同字同级升级、神将字凑对成神将卡直接入架；不可合成的两张卡互拖仍是换位，拖到空槽即移位），悬停在可合成的卡上亮绿框预兆、合成后卡槽弹跳，被吸收单位的已佩装备自动回库；能合成的卡会金框脉动并亮「合」角标，场上能两两合成（或与架子卡凑对）的单位也会金圈脉动亮「合」角标；拖拽字/塔到目标格合成或换位；拖到架子空格回收；长按架上的字弹出出售/献祭面板；顶栏「装」按钮开合装备栏（有部件/装备可合成时按钮亮金边），栏内点部件合成装备、点装备再点塔佩戴；「铲」开垦「封」字地块或把塔铲回架子（双击「封」字地块也可直接弹开垦确认；无铲时短按铲子钮花桃补一把）；P 或按钮暂停；1/2/3/4 倍速循环。

## 2.0 新增（#36–#50）

- **倍速与实时 DPS**：1→2→3→4 倍速循环（偏好入档下局沿用，高倍速积压保护防螺旋死亡；备战倒计时自动开波，可提前叫波拿桃）；顶栏「伤」开合实时伤害榜——前五塔累计伤害与平均 DPS，交战计时只计开波期，500ms 刷新。
- **上局阵容占位**：结算保存阵容快照（字/等级/索敌/离路环距/伤害/原位），下局首波备战期画金框虚线占位建议；每日/每周同种子直接原位复刻，普通局按「环距匹配 + 高伤塔优先近路 + 近入口」重排；落子或开波自动隐去。
- **新手三步引导**：首局依次引导召唤 → 放字 → 再放/合成，气泡不拦截操作、条件轮询自动翻步、暂停挂起；完成或跳过入档，不再打扰。
- **离屏静态层**：远景、砖路、建筑三幅预渲染画布按原层次合成，每帧从逐格数百次绘制降为三次贴图；换图/开垦/改尺寸才重画，实测同场景（12 塔 + 40 怪）单帧 0.502ms→0.317ms。
- **Boss 池轮换**：玄甲（护甲 8，存活时全军攻击 -25%）、唤魂（每 4 秒召 2 只小鬼）、狂暴（半血移速 ×1.6 + 红环）、隐匿（周期遁形 2 秒不可索敌）四种鬼将按波次公式轮换（不用 RNG，保日/周种子回放）；入场点名 + 横幅，专属碎片掉落与鬼将种类绑定。
- **传说词条**：波间三选一约 5% 概率降临一张金红传说卡——天罡战气（全体攻击 +35%）、神行法（攻速 +25%）、冰封千里（敌速 -20%，上限 -50%）、点石成桃（过波 +30 桃）、蟠桃盛会（立即 +5 心、心上限 +3）；与普通词条同池互斥不重复。
- **成就与称号**：29 条成就覆盖波次/累计击杀/图鉴等级/神将收集/神兵锻造/每日每周/新手引导/PVP；达成自动解锁并获称号，图鉴「成就」页签点选佩戴/卸下，主菜单与结算页展示佩戴称号。
- **神将升星**：同名神将合并改为升星（任意等级可作材料，每星攻击 +8%、技能效果 +15%，架子/棋盘/拖拽三路判定 + 金圈高亮），棋盘字牌下金星标、架子星徽；满星解锁 12 位神将各自专属被动（火眼金睛破甲、督战、寒潮、三头六臂、破军暴击等），接入攻击/索敌/命中/击杀/开波五条链路；图鉴记历史最高星，阵容快照带星。
- **神将熟练度**：上场次数跨局累计（每局每神将只记一次），5/15/40 次解锁「初试锋芒 / 驾轻就熟 / 出神入化」三档纯表现特效（技能双环 → 字牌金描边 → 牌框常驻金晕 + 施放花火），选中面板与图鉴展示档位。
- **扩系八塔**：新增毒（腐蛊染毒叠层，无视护甲 DoT）、雷（连环闪电 3 跳、逐跳 -25%）、冰（命中减速）、锤（先削甲后结算，本击即受益）；Lv3 可花 12 桃在详情面板二选一进阶（蚀骨毒/瘴疫、连环雷/霹雳、严寒/冰晶爆、碎甲锤/重金锤，择一不可改）。字池扩至 27 字，同机器人 A/B 对照（新池 11/8/10 波 vs 旧池 6/10/10 波）无平衡回归。
- **全服风云榜**：零依赖 Node 服务按北京时间分桶的今日/本周榜（前 20，同名只留最佳）；每局结算自动上传最佳波次，主菜单、暂停、结算三入口，双页签、本尊高亮，局内改名；无 API 的纯静态托管自动降级，不影响单机。
- **异步 PVP 镇守/讨伐**：把终局阵容 + 地图种子上传当别人的关底；讨伐方用同种子战场 + 60 桃军饷迎战 1–3 阵镜像守军（4 单位/阵，按神将/等级/星级/波次放大，金环标记），破阵/折戟分别结算并计入镇守方守成/被破；PVP 不计历史最高波、不上风云榜、不覆盖上局阵容。
- **存档云同步**：8 位设备码（去掉 I/O/0/1 防手抄混淆）绑定云端；本地落盘后 6 秒静默合并上传，换机输入设备码一键恢复魂晶/天赋/图鉴/碎片/异变纪录与名号；服务端 2000 槽位、单档 ≤64KB，未绑定或离线完全不影响单机。

## 运行方式

**纯单机**：无构建步骤，直接用浏览器打开 `index.html` 即可（字体为本地子集，离线可玩）；或任意静态服务器托管。静态托管下风云榜 / PVP / 云同步的接口自动降级，不影响单机玩法。

**完整服务**（风云榜 + PVP + 云存档）：`server.js` 是零依赖 Node 单进程，同时托管静态站与 API，存档落在站点目录之外的 `../wukong-td-api/data.json`（防止被静态服务下载）：

```bash
node server.js                                        # 默认 80 端口，静态根=脚本目录
PORT=8088 WK_ROOT=./dist WK_DATA=/tmp/wukong-api node server.js   # 本地测试
```

线上部署（塔防项目已授权直传）：`bash scripts/deploy-80.sh` —— 上传文件、写 systemd 单元、放行 80、内网自测，约 30 秒。外网验收 `curl -I http://43.99.15.109/`。

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/api/board?kind=daily\|weekly` | GET | 今日/本周风云榜前 20（北京时间分桶，同名只留最佳） |
| `/api/score` | POST | 上传战绩 `{name,wave,kills,kind,endless}` |
| `/api/pvp/list?name=` | GET | 镇守阵列表（排除自己，按守成降序，前 40）+ 我的守成记录 |
| `/api/pvp/defense` | POST | 上传/覆盖镇守阵 `{name,wave,seed,lineup}`（阵容 ≤12 单位） |
| `/api/pvp/result` | POST | 讨伐结算 `{attacker,defender,win,wave}`，累计守方守成/被破 |
| `/api/cloud?code=` | GET | 按 8 位设备码读取云存档 |
| `/api/cloud` | POST | 上传/覆盖云存档 `{code,name,data}`（≤64KB，2000 槽位按最近同步淘汰） |

接口均带参数校验、滑动窗口限流（云存档读取 40 次/10 分钟、上传 60 次/10 分钟）与静态路径穿越防护；数据原子落盘，重启不丢。

已适配手机竖屏：舞台整体等比缩放（transform scale），触控拖拽/点选与桌面鼠标一致，支持高分辨率屏（背缓冲密度自适应），禁用了双击缩放/下拉刷新/橡皮筋滚动等浏览器默认手势；刘海屏读取 env(safe-area-inset-*) 留边，画面不被挖孔/圆角遮挡。背景音乐为 WebAudio 程序合成的低频氛围音（55/82.41/110Hz 三音呼吸漂移），随音效开关启停，零素材零加载。

iOS Safari 缩放封锁为三层保险：viewport `user-scalable=no` + 全页 `touch-action`（舞台 none、页面 manipulation）+ JS 拦截（Safari 专有 gesturestart/change/end 事件拦捏合；320ms 内两次 touchend 拦双击，输入控件与按钮除外以免吞连点）——被忽略 viewport 的 iOS 版本也可靠 JS 层兜住。

## 技术栈

原生 JavaScript + Canvas 2D（渲染）+ DOM Overlay（面板），零第三方依赖，可平滑移植微信小游戏。展示字体「马善政毛笔体」已子集化（约 340KB woff2，仅含游戏用字）。服务端为零依赖 Node（`http`/`fs`/`path`），单进程同时提供静态站与 JSON API，数据落盘在站点目录之外。

## 平衡基线（M5 机器人自测）
